# LLM-Powered Autonomous Mobile Robot

An autonomous mobile robot controlled through natural language
using an LLM-based task planner, ROS 2, and Gazebo.

## Goal

Enable a user to issue commands such as:

"Go to the blue box and return to the starting position."

The LLM interprets the command and converts it into a sequence
of high-level robot actions executed through ROS 2.
